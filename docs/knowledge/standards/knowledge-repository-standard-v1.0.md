# Knowledge Repository Standard v1.0

## Purpose

Define the standard for preserving, evolving, and recovering organizational knowledge within AI Company OS.

## Principles

- Repository First
- Single Source of Truth
- Knowledge over Chat
- Continuous Learning
- Recoverability
- Traceability

## Repository Role

The Repository is the permanent knowledge repository.

Chats are temporary workspaces.

## Single Source of Truth

All approved knowledge shall be preserved in the Repository.

## Knowledge Classification

- Owner Knowledge
- Executive Knowledge
- Learning
- Standards
- Reports
- Bootstrap

## Directory Standard

docs/knowledge/

## Naming Standard

kebab-case

Example

knowledge-repository-standard-v1.0.md

## Metadata Standard

Every knowledge artifact shall contain

- title
- version
- owner
- status
- approval authority
- related artifacts

## Ownership

Knowledge ownership shall be explicitly assigned.

## Update Workflow

Interview

↓

Review

↓

Knowledge Update

↓

Repository Registration

↓

Validation

↓

Version Update

## Validation

Knowledge must be reviewed before becoming Approved.

## Versioning

Knowledge follows semantic versioning.

Major.Minor

## Traceability

Every knowledge update must reference

- Executive Interview
- Strategic Dialogue
- Decision Report
- Related Case

## Recovery Principle

Repository must be sufficient to reconstruct Executive knowledge without relying on chat history.

## Governance

This standard is governed by Knowledge Governance v1.0.
