# ADR — Autonomous Revenue Operating Roadmap — 2026-09-02

## Decision

Existing technical direction is retained but sequencing is modified.

### Approved Sequence

1. CEG-02 Real ODL Evidence Closure
2. Exactly One Real KAVORA Revenue Workflow
3. Adaptive Revenue Decision Gate
4. Owner Dependency + Revenue / Information Gain Measurement
5. Multi-role Runtime
6. Long-running Goal Loop
7. Cross-Engine Memory / Cost Routing
8. Dashboard only after necessity is evidenced

## Rationale

Persistent execution alone does not demonstrate business success. Before scaling role runtime complexity, KAVORA must prove one real Revenue Workflow can react to real Evidence and change course when the current Hypothesis fails.

## Not Authorized

- Production Adoption
- main merge of the LangGraph PoC
- Multi-role Expansion before prior gates
- Dashboard-first implementation
