# Terminology Style Guide v1.1

## Purpose

This guide standardizes terminology, naming conventions, abbreviations,
capitalization, and language usage across AI Company OS documentation.

---

# Language Rules

- Architecture documents: English
- Business discussions: Japanese or English
- Technical identifiers: English

---

# Capitalization

Use Pascal Case for:

- Business Domain
- Executive Roles
- Document Titles

Use lower camelCase for:

- Variables
- JSON fields

Use UPPER_SNAKE_CASE only for constants.

---

# Naming Conventions

Preferred examples

- Architecture Baseline
- Company KPI
- Domain KPI
- Operational KPI
- Repository Validation

Avoid inconsistent variants.

---

# Abbreviations

Approved abbreviations

- CEO
- CMO
- CPO
- ADR
- KPI
- API
- ROI

Avoid introducing undocumented abbreviations.

---

# Governance

New terminology shall be registered in the Glossary before use.

Changes to terminology standards require architecture review.
