# KAVORA Autonomous Revenue Loop v0.1

## Canonical Loop

`Evidence → Diagnosis → Hypothesis → Action → Result → Learning → Continue / Revise / Stop / Scale`

## Required Cycle Measures

- Revenue
- Net Profit
- Economic Progress
- Information Gain
- Execution Cost
- Owner Intervention
- Hypothesis Status
- Next Decision

## Decision Rules

### Revenueあり
Economicsを確認しContinue / Scaleを判断する。

### Revenueなし + Information Gainあり
Hypothesisを更新し次Experimentへ進む。

### Revenueなし + Information Gainなし
同一Actionの再実行を禁止する。

### Hypothesis反証
Revise / Stop。

### Viable Next Hypothesisなし
`NO VIABLE PATH — CURRENT EVIDENCE`

## Threshold Rule

「3ヶ月」等の固定期間をExternal Evidenceなしに標準化しない。ThresholdはRevenue EngineごとのEconomics、Evidence、Cost、Information Gainから決める。
