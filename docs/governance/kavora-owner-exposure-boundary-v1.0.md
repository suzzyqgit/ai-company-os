# KAVORA Owner Exposure Boundary v1.0

## Boundary

Revenue獲得のためにOwner本人の以下を公開しない。

- 顔
- 声
- 身体

## Non-Expansion Rule

このBoundaryのみを根拠として、Anonymous Text、KAVORA Brand、AI Character、AI Voice、Faceless Contentまで禁止したとは解釈しない。

## Privacy Reference

Owner personal phone number / home addressはPrivate / Default Non-Disclosureとし、別Governance Ruleを継続適用する。
